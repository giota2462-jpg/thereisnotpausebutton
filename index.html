There Is No Pause Button!

Created by Scott Cawthon • Released: May 16, 2013

About the Game

There Is No Pause Button! is an action-packed 2D auto-runner developed by Scott Cawthon for Android devices in May 2013.

Unlike traditional platformers, your character never stops moving. You must navigate through increasingly difficult obstacles, spikes, and traps with pixel-perfect precision.

Controls & Mechanics

  • Tap Screen: Jump
  • Hold Screen: Higher Jump
  • Pause Menu: Non-existent! As the title suggests, there is no way to pause the game once a level starts.

Developer Info

This game was created by Scott Cawthon using Clickteam Fusion, a year before he released the original Five Nights at Freddy's (2014).

This page serves as a digital archive for the original v1.0 APK build.
